自动验证没有调用优化模型，也没有往源会话发送指令。新增自动化使用临时样例，覆盖追加修正、删除后不串目标、归档、身份校验、截断、文件损坏、取消和只读 RPC 方法限制。真实对话只输出状态和覆盖统计，正文不写入此记录。

窗口检查截图和运行记录保存在 `.cache/local-context-ui-check/`，属于本地材料，不提交或打包。应用的绑定文件仅保存 ID、目录和标题；缓存中的对话正文不写入绑定文件。

## 仍需用户体验确认

1. 在“选择本机会话”中按标题与项目目录选定目标；关闭并重新打开助手后，核对仍是同一会话。
2. 在原 Codex 对话补充一条明确修正，待其保存后点击助手“刷新”，核对检查时间及“内容有更新”状态；再输入含指代的原话，确认优化结果遵循修正。不要仅凭“已读取”认为改写质量已经通过。
3. 切换到另一项目会话，确认标题、ID、目录都变化；若删除或移动原记录，刷新应报告失效，不应自动改绑其他项目。
4. 生成中点击取消，再重试；确认取消后的迟到结果不会覆盖新结果。现有简单/专业、复制、分享快照入口分别体验。
5. Windows 登录与 Codex 开关联动仍需在真实桌面环境人工确认；隔离配置的窗口检查不能替代重启测试。

这些步骤不需要复制分享链接。若列表为空或目录不正确，通过“更换数据目录”选择包含 `sessions` 的 Codex 数据目录；项目目录只是筛选条件，不能替代会话选择。
